# Дополнительное соглашение к договору на оказание услуг от «11» октября 2024 г.

г. Москва                                                                                                             «7» октября 2026 г.

По желанию Заказчика в лице генерального директора ООО «КФС» Щербаковой Татьяны Леонидовны, для программного обеспечения, разрабатываемого в рамках текущего договора об оказании услуг, будет добавлен новый функционал для более точного управления системой и обеспечения возможности экспорта данных о планах производства в сторонние системы.

В рамках данных работ Исполнитель в лице Кузнецова Михаила Андреевича выполняет работы по разработке и обновлению существующего ПО. Срок выполнения работ составляет 14 календарных дней, сумма оплаты за работы составляет 48000 (сорок восемь тысяч) рублей, в т.ч. 9600 (девять тысяч шестьсот) рублей в качестве авансового платежа.

Далее приведено техническое задание на доработки программного обеспечения по конфигурации параметров производства и разработке листа «Импорт» в Excel-файле плана производства на смену.

## 1. Общие сведения

**Цель:** позволить пользователю самостоятельно настраивать параметры производства (линии, оборудование, возвратные массы, постоянные величины, **типы зефира и правила расчёта отчёта**) в интерфейсе без привлечения программиста и обеспечить передачу данных об изготовленной продукции во внешнюю систему через лист «Экспорт».

**Состав работ:** 2 этапа.

- Этап 1 — правки по производству (конфигурирование параметров в интерфейсе);
- Этап 2 — новый лист «Экспорт» в отчёте.

**Ожидаемый эффект:** любое изменение параметров (новая линия, новое оборудование, новый режим возвратных масс, изменение интервалов, **новый вид зефира, изменение правил расчёта отчёта**) выполняется пользователем самостоятельно в окне «Производство» и не требует правки кода.

## 2. Что будет добавлено / изменено

### 2.1. Этап 1. Окно «Производство» (меню «Реестры»)

**Было (правила «зашиты» в код):**

- линия «Сборка ящиков» определялась по внутреннему номеру 37 (проверка встречалась в ~25 местах кода);
- продукция «телевизор» определялась по слову «телевизор» в названии;
- правила возвратных масс определялись по названиям линий;
- участие линий в датировании — по зашитым спискам номеров линий для каждой категории продукции;
- значения по умолчанию для линий хранились в отдельном конфигурационном файле;
- **правила расчёта отчёта по продукции — по зашитым правилам: варочные линии зефира — по зашитому списку номеров; итоги по категориям упаковки (зефир, конфеты, суфле) — по зашитым номерам линий; виды зефира (агар, желатин, без сахара, фруктоза, на пектине, крем-десерт) — по захардкоженным названиям продукции.**

**Станет:**

Новое окно «Производство» в меню «Реестры» — единое окно всех производственных настроек, **пять** вкладок:

- **Линии** — полная таблица линий: наименование, производительность, тип, подготовительное и заключительное время, рабочие, возвратные массы, датирование, **расчёт (варка), расчёт (упаковка)**, цвет. Редактирование прямо в ячейках; выделение нескольких линий и изменение разом («Изменить выделенные»); добавление и удаление линий кнопками. Удаление линии, у которой есть планы, блокируется.
- **Оборудование** — справочник оборудования (Торнадо, Мондомикс, ЗМ №1 и т. д.): добавление, переименование, удаление. Новое оборудование сразу появляется в списках выбора в окнах плана и продукции. Удаление оборудования, используемого в слотах продукции, блокируется.
- **Возвратные массы** — справочник режимов: название, тип формулы (фиксированное значение или коэффициент), коэффициенты для зефира, суфле, конфет. Можно менять коэффициенты, добавлять новые режимы и удалять неиспользуемые — без правки кода. Удаление режима, на который ссылаются линии, блокируется.
- **Постоянные величины** — интервал варки, интервал упаковки, производительность одной и двух завёрточных машин.
- **Типы зефира** — справочник видов зефира: наименование (текст итоговой строки отчёта «ИТОГО …»), флаг «по умолчанию» (вид, к которому относится продукция, если у неё явно не выбран вид). Добавление, переименование, удаление; порядок строк определяет порядок итоговых строк в отчёте. Конкретный вид выбирается для каждой продукции отдельно — дропдауном «Тип зефира» в карточке продукции; при переносе данных виды проставлены по прежним правилам названий, чтобы отчёт совпадал с прежним.

Поля, ранее добавленные в форму линии, перенесены в окно «Производство» (вкладка «Линии»):

- «Роль» — «Варка / Упаковка / Сборка ящиков»;
- «Возвратные массы» — режим из справочника или «не участвует» (после переноса данных доступны 4 режима; новые режимы из справочника появляются в списке автоматически);
- «Учитывать в датировании» — галочка. На доске «Компания» в форме линии остались только сменные значения (время работы, подготовительное/заключительное на смену, ответственные, детектор).

**Вкладка «Линии» — два новых поля:**

- **«Расчёт (варка)»** — галочка: линия участвует в расчёте варки зефира и его видов. Заменяет зашитый список варочных линий.
- **«Расчёт (упаковка)»** — мультивыбор категорий итогов (Зефир / Конфеты / Суфле; пусто — «не участвует»): определяет, в итоги каких категорий попадает продукция линии. Линия может давать итоги по нескольким категориям. Заменяет зашитые номера линий по категориям итогов.

Карточка продукции, вкладка «Справочная информация» — галочка «Телевизор»: при включении штуки продукции включаются в расчёт длительности сборки ящиков. Дропдаун «Тип зефира» — выбор вида зефира для конкретной продукции из справочника «Типы зефира» (можно не выбирать — тогда в отчёте применяется вид «по умолчанию»).

Изменение поведения датирования: участие в датировании определяется линией, а не категорией продукции. Датированию подлежит вся продукция, изготовленная на линиях с включённой галочкой (раньше — только отдельные категории).

Интервал упаковки стал настройкой: раньше к планам упаковки прибавлялось зашитое значение 10 минут; теперь применяется настройка «Интервал упаковки» из «Постоянных величин» (начальное значение — 15 минут).

Перенос данных: текущие настройки из «зашитых» правил и конфигурационного файла переносятся в новые поля так, чтобы отчёт оставался совпадающим с прежним (кроме интервала упаковки и формулировок названий оборудования — см. п. 5 и п. 7). **Новые поля «Расчёт (варка)», «Расчёт (упаковка)» и справочник «Типы зефира» заполняются из зашитых правил так, чтобы отчёт остался совпадающим с прежним.**

Формулировки оборудования в отчёте: названия выводятся из справочника; для завёрточных машин — полные названия («Завёрточная машина №1» вместо «ЗМ №1»). Это косметическое изменение.

### 2.2. Этап 2. Лист «Экспорт» в отчёте

Третий лист отчёта «Экспорт» — плоский список изготовленной продукции для передачи во внешнюю систему.

| Колонка | Содержание |
|---|---|
| Дата | дата смены, формат «ДД.ММ.ГГГГ» |
| Локация | полное наименование линии |
| Наименование | название продукции из реестра |
| EK_SKU | название продукции из реестра |
| Время смены | время изготовления на линии, формат «чч:мм - чч:мм» |

Правила формирования:

- данные берутся с листа «Упаковка» в полном объёме: каждая линия — отдельная локация, вся продукция со всех линий, включая повторяющиеся позиции;
- строки упорядочены по времени начала изготовления по возрастанию;
- для первой позиции на каждой линии из времени начала вычитается подготовительное время линии, для последней к времени конца прибавляется заключительное (пример: при подготовительном и заключительном по 30 минут первая позиция начинается в 7:30 вместо 8:00, последняя заканчивается в 20:00 вместо 19:30);
- лист присутствует в отчёте всегда, кроме смен, когда на участке упаковки не изготовлено ни одной единицы продукции.

## 3. Критерии приёмки

### Этап 1

Окно «Производство» и вкладки:

- В меню «Реестры» доступно окно «Производство» с **пятью** вкладками: «Линии», «Оборудование», «Возвратные массы», «Постоянные величины», **«Типы зефира»**.
- Вкладка «Линии» отображает все существующие линии с данными (наименование, производительность, тип, подготовительное и заключительное время, рабочие, возвратные массы, датирование, **расчёт (варка), расчёт (упаковка)**, цвет); изменения в ячейках сохраняются; «Изменить выделенные» применяет изменения ко всем выделенным линиям разом.
- Добавление линии кнопкой доступно; новая линия появляется в списках выбора в окнах плана и продукции.
- Удаление линии, у которой есть планы, блокируется системой с понятным уведомлением; линия без планов удаляется.
- Вкладка «Оборудование»: оборудование добавляется, переименовывается и удаляется; изменения сразу видны в списках выбора в окнах плана и продукции. Удаление оборудования, используемого в слотах продукции, блокируется с уведомлением.
- Вкладка «Возвратные массы»: создаётся новый режим, меняются тип формулы и коэффициенты (зефир, суфле, конфеты); новые значения применяются в расчётах без обращения к разработчикам. Удаление режима, на который ссылаются линии, блокируется с уведомлением.
- Вкладка «Постоянные величины»: интервал варки, интервал упаковки, производительность одной и двух завёрточных машин меняются в интерфейсе и применяются в расчётах.
- **Вкладка «Типы зефира»:** добавляется новый вид, меняются наименование и флаг «по умолчанию», удаляется неиспользуемый вид; порядок строк определяет порядок итоговых строк в отчёте. Удаление вида, на который ссылается продукция, блокируется. Набор и названия видов зефира в отчёте соответствуют справочнику.

Поля линий и продукции:

- Поле «Роль» (окно «Производство» → «Линии»): линия, отмеченная «Сборка ящиков», обрабатывается как сборка ящиков независимо от её внутреннего номера; линия с номером 37 без отметки «Сборка ящиков» таким поведением уже не обладает.
- Поле «Возвратные массы» (окно «Производство» → «Линии»): список содержит режимы справочника + «не участвует»; смена режима меняет расчёт возвратных масс линии в соответствии с выбранным режимом; поведение не зависит от названия линии.
- **Поле «Расчёт (варка)» (окно «Производство» → «Линии»):** отметка у линии включает её продукцию в расчёт варки зефира и его видов; без отметки линия в расчёт варки не участвует. Поведение не зависит от номера линии (ранее — зашитый список варочных линий).
- **Поле «Расчёт (упаковка)» (окно «Производство» → «Линии»):** выбранные категории (Зефир / Конфеты / Суфле) определяют, в итоги каких категорий попадает продукция линии; линия может участвовать в нескольких категориях; без выбора — не участвует. Поведение не зависит от номера линии (ранее — зашитые номера линий по категориям).
- Галочка «Телевизор» в карточке продукции: при включении штуки продукции включаются в расчёт длительности сборки ящиков, при выключении — нет; поведение не зависит от наличия слова «телевизор» в названии.
- Поле «Тип зефира» в карточке продукции (дропдаун из справочника «Типы зефира», можно очистить): определяет, в какой вид зефира попадает продукция в итогах отчёта; без выбора — вид «по умолчанию». Поведение не зависит от наличия слова вида в названии (ранее — по захардкоженным названиям).
- Датирование: вся продукция, изготовленная на линии с включённой галочкой «Учитывать в датировании», датируется вне зависимости от категории продукции; продукция на линиях без галочки не датируется.

Перенос данных и самостоятельность:

- После переноса данных настройки существующих линий сохранены: отчёт по упаковке за контрольный период совпадает с отчётом, сформированным до изменений, за исключением интервала упаковки (применяется настройка 15 минут вместо прежних зашитых 10) и формулировок названий оборудования.
- **Новые поля «Расчёт (варка)», «Расчёт (упаковка)» и справочник «Типы зефира» заполнены из зашитых правил: отчёт за контрольный период, сформированный после изменений, совпадает с прежним (кроме вышеуказанных исключений).**
- Сценарий «без программиста»: пользователь создаёт новую линию, добавляет оборудование, создаёт новый режим возвратных масс, меняет постоянные величины **и виды зефира** — всё через окно «Производство», и изменения вступают в силу.

### Этап 2

Лист «Экспорт» — третий лист отчёта. Он присутствует во всех отчётах, где на участке упаковки изготовлена хотя бы одна единица продукции; на сменах с нулевой выработкой участка упаковки лист отсутствует.

- Лист содержит ровно пять колонок: Дата, Локация, Наименование, EK_SKU, Время смены.
- Дата — дата смены в формате «ДД.ММ.ГГГГ»; Время смены — в формате «чч:мм - чч:мм».
- Локация — полное наименование линии; каждая линия выводится как отдельная локация.
- Наименование и EK_SKU — название продукции из реестра (одно и то же значение в обеих колонках).
- Объём данных совпадает с листом «Упаковка»: все позиции со всех линий, включая повторяющиеся; строки упорядочены по времени начала изготовления по возрастанию.
- Первая позиция на каждой линии: время начала = старт изготовления − подготовительное время линии; последняя: время конца = конец изготовления + заключительное время линии. Проверка эталонным примером: линия с подготовительным и заключительным по 30 минут — первая позиция 7:30 вместо 8:00, последняя 20:00 вместо 19:30.

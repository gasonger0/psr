# Настройка производства без программиста: что уже готово и что в работе

## Этап 1 - правки по производству

Раньше многие правила работы производственных линий были «зашиты» в код программы: чтобы добавить линию с особым поведением или изменить какой-то параметр, требовалась правка кода и участие программиста. Мы переносим эти правила в интерфейс, чтобы параметры вы могли менять сами.

До изменений программа определяла правила так:

- линия «Сборка ящиков» — по внутреннему номеру 37 (проверка встречалась в ~25 местах кода);
- продукция «телевизор» — по слову «телевизор» в названии;
- правила возвратных масс — по названиям линий;
- участие линий в датировании — по зашитым спискам номеров линий для каждой категории продукции;
- значения по умолчанию для линий хранились в отдельном конфигурационном файле.

Теперь всё это — обычные поля, которые редактируются в интерфейсе:

1. **Роль линии** — переключатель «Варка / Упаковка / Сборка ящиков» в форме линии.
2. **Возвратные массы** — выпадающий список в форме линии (4 правила + «не участвует»).
3. **Учитывать в датировании** — галочка в форме линии.
4. **Телевизор** — галочка в карточке продукции (вкладка «Справочная информация»): если включена, штуки добавляются в расчёт длительности сборки ящиков.

Важный нюанс поведения: участие в датировании теперь определяется линией, а не категорией продукции. Раньше линия датировалась только по отдельным категориям, теперь — вся продукция, изготовленная на отмеченных линиях. Перенос данных выполнен так, что текущие настройки сохранились, и отчёт совпадает с прежним.

Мы делаем единое окно **«Производство»** (меню «Реестры»), в котором собраны все производственные настройки. Четыре вкладки:

- **Линии** — полная таблица линий: наименование, производительность, тип, подготовительное и заключительное время, рабочие, возвратные массы, датирование, цвет. Редактирование прямо в ячейках; можно выделить несколько линий и изменить их разом («Изменить выделенные»). Добавление и удаление линий — кнопками (линию, у которой есть планы, система удалить не даст).
- **Оборудование** — справочник оборудования (Торнадо, Мондомикс, ЗМ №1 и т.д.): добавлять, переименовывать, удалять. Новое оборудование сразу появляется в списках выбора в окнах плана и продукции.
- **Возвратные массы** — справочник режимов: название, тип формулы (фиксированное значение или коэффициент) и коэффициенты для зефира, суфле, конфет. Коэффициенты можно менять и добавлять новые режимы — без правки кода.
- **Постоянные величины** — интервал варки, интервал упаковки, производительность одной и двух завёрточных машин.

После завершения этого этапа ни одно изменение параметров не потребует программиста: новая линия, новое оборудование, новый режим возвратных масс или изменение интервалов — это минута работы в окне «Производство».


Оценки — в человеко-днях работы одного разработчика.

| Фаза | Человеко-дни |
|---|---|
| Анализ и проектирование: инвентаризация всех «зашитых» чисел по 3 модулям расчёта, схема 3 новых таблиц, разбор устаревших колонок | 2–3 |
| Бэкенд: миграции и модели, API справочников с защитой от удаления используемых записей, массовое редактирование линий, перевод расчётов на настройки из базы | 3–4 |
| Фронтенд: окно «Производство» с 4 вкладками, редактирование в таблице, окно массового изменения, переключение окон плана и продукции на справочник | 3–4 |
| Тестирование и регрессия: обновление автотестов, сквозная ручная проверка всех вкладок и расчётов | 2–3 |
| **Итого** | **10–15** |

Здесь больше «объёмной» работы: 3 новые таблицы, ~10 новых точек API, крупное окно интерфейса и замена настроек в трёх модулях расчёта.

## Этап 2 - новый лист «Импорт» в отчёте

В отчёт добавляется третий лист **«Импорт»** — плоский список изготовленной продукции для передачи во внешнюю систему. Столбцы: **Дата** (дата смены, формат «ДД.ММ.ГГГГ»), **Локация** (полное наименование линии), **Наименование** (название продукции из реестра), **EK_SKU** (название продукции из реестра), **Время смены** (время изготовления на линии, формат «чч:мм - чч:мм»).

Как формируется лист:

- данные берутся с листа «Упаковка» в полном объёме: каждая линия считается отдельной локацией, вся продукция со всех линий попадает в «Импорт» (включая повторяющиеся позиции);
- строки упорядочены по времени начала изготовления по возрастанию;
- для первой позиции на каждой линии из времени начала вычитается подготовительное время линии, для последней — прибавляется заключительное (пример: на линии с подготовительным и заключительным по 30 минут первая позиция начинается в 7:30 вместо 8:00, последняя заканчивается в 20:00 вместо 19:30);
- лист присутствует в отчёте всегда, кроме смен, когда на участке упаковки не изготавливается ни одной единицы продукции.

### Оценка (человеко-часы)

| Фаза | Человеко-часы |
|---|---|
| Разбор структуры отчёта (как устроены листы «Варка»/«Упаковка», откуда берутся времена и названия) | 2–4 |
| Реализация: сбор данных с листа упаковки, сортировка, поправка первой/последней позиции на линии, третий лист, правило «пустой упаковки» | 4–6 |
| Проверка: сверка с листом «Упаковка», форматы дат и времени, граничные случаи | 2–4 |
| **Итого** | **8–14** |

≈ *1–2* рабочих дня одного разработчика.
